To-Do List Manager — Week 1: Python CLI Application

**Internship:** Junior Python Developer
**Task:** Week 1 — Python CLI Application Design and Implementation
**Deliverable:** A self-contained, dependency-free command-line To-Do List Manager.

A small but production-shaped command-line application for managing a personal
task list. It supports adding, listing, completing, re-opening, editing,
removing, searching and exporting tasks, with priorities, due dates and
persistent JSON storage. The whole project runs on a stock Python 3.9+
installation — **no third-party packages are required**.
